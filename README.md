Find all possible solutions for the popular Game Pigeon IOS app, Word Hunt! 

The user interface is built with HTML and CSS and the back-end uses JS. The core of the solver is a depth-first search (DFS) that explores every possible path through the 4×4 grid while checking prefixes against a dictionary to avoid wasting time on impossible words.
